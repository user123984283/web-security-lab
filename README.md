Лабораторна робота №2

Тема: Керування версіями програмного проєкту засобами GitHub.

Опис проєкту

Проєкт містить вебсторінку входу до інформаційної системи, створену під час лабораторної роботи №1 з використанням HTML, CSS та JavaScript.

Форма містить поле електронної пошти, поле пароля, кнопку «Увійти» та перевірку введених даних.

Призначення

Мета проєкту — навчитися використовувати GitHub для зберігання файлів, відстеження змін, створення гілок та об'єднання змін.

Запуск проєкту

Завантажити файл index.html.

Відкрити його у веббраузері.

Ввести електронну пошту та пароль.

Натиснути кнопку «Увійти» для перевірки введених даних.
